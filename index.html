Paste the sequence, describe the mutation and get a primer pair following the QuikChange II rules.

0 nt

How the sequence and positions work
  • Paste the full gene or plasmid if possible. A fragment also works if it has at least 60 nt, ideally 30 to 50 bases on each side of the mutation. The primer itself uses about 10 to 22 bases on each side.
  • Positions are counted from the first pasted base (position 1). With a fragment, A123G refers to the 123rd base of the fragment, not of the gene.
  • For amino acid substitutions, enter the position of the A of the ATG within the pasted sequence. If the fragment starts elsewhere in the gene, use a nucleotide-level mutation instead.
  • The tool checks that the original base or amino acid matches your sequence and warns you if it does not, which helps catch numbering errors.
  • Paste the 5′→3′ strand, the same one as the forward primer. The reverse primer is its reverse complement.
  • The tool picks the shortest primer that meets all criteria. Your own primer can be longer or placed differently and still be valid, so compare Tm, GC, length and G/C ends rather than the exact sequence.

How to write an amino acid mutation
  • Choose Amino acid substitution and write the original amino acid, the residue number and the new one. To change cysteine 45 to alanine, write C45A.
  • Residues are counted from the ATG, where the methionine is residue 1. Enter in the field below the position of the A of that ATG in the pasted sequence. Example: if the ATG starts at position 250 and the cysteine is residue 45, write C45A and 250.
  • The tool reads the codon of that residue, checks that it encodes the original amino acid and warns you if it does not. It then picks the new codon with the fewest base changes (for example, TGC to GCC for Cys to Ala).
  • If you already know where the residue sits in the pasted sequence (for example, position 996 of the plasmid), fill in the optional field "position of the residue" and write only the residue number in the mutation, such as C50A. The tool finds the codon near that position, checks that it encodes the original amino acid and ignores the ATG position. The codon it used is shown in the result.
  • If your plasmid has a tag before the gene, or your protein numbering does not start at the ATG of the pasted sequence, count from the first codon of the numbering you use and enter the position of that codon.
  • If the numbering is complicated, use Nucleotide substitution instead: find the codon in the sequence, count the position of the base that changes and write, for example, T123G.
  • If you are not sure of the residue number, try a guess. If it is wrong, the error message tells you which amino acid was found at that position.

If filled, this replaces the ATG position above. Enter where the residue to mutate sits in the pasted sequence (any of its three bases works).
